GarageSim

A VR training application built with Unity to help automotive vocational students practice basic vehicle maintenance in a virtual environment.

Unity VR C# Education
View on GitHub

Overview

GarageSim is a VR application I developed for my final-year project. The goal was to give automotive vocational students a way to practice vehicle maintenance without relying on physical equipment.

Using a VR headset, students can interact with engine components and tools in a virtual workshop while following the maintenance steps. The application is intended to provide additional practice before working with real vehicles.

Key Features

  • Interactive engine components
  • Guided maintenance procedures
  • Progress tracking

Challenges & Learnings

The most challenging part of this project was implementing VR interactions that felt consistent and easy to use. I spent a lot of time adjusting object interactions, grabbing mechanics, and tool behavior to make the experience feel more natural.

This project was my first experience building a complete VR application with Unity. Along the way, I learned how to use the XR Interaction Toolkit, optimize scenes for VR devices, and design interactions that are simple enough for first-time users.
